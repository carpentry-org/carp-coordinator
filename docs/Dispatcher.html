Dispatcher

manages event subscriptions and synchronous broadcasting.

broadcast!

defn

(Fn [(Ref (Dispatcher a) b), (Ref a c)] (Array String)) 

                        (broadcast! d event)

synchronously sends an event reference to all registered handlers. Snapshots the handlers before iteration to ensure safety if handlers modify subscriptions. Returns an array of error messages from handlers that failed.

subscribe!

defn

(Fn [(Ref (Dispatcher a) b), (Ref (Fn [(Ref a c)] (Result () String)) d)] Long) 

                        (subscribe! d handler)

registers a handler function and returns a unique ID for unsubscription. The handler will receive a reference to the event and should return a Result.

unsubscribe!

defn

(Fn [(Ref (Dispatcher a) b), Long] Bool) 

                        (unsubscribe! d id)

removes a handler by its ID. O(n) complexity.
