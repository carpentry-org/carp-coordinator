(Fn [(Ref (Scheduler a) b), a, Long] Long)

defn

(Fn [(Ref (Scheduler a) b), a, Long] Long) 

                        (schedule-periodic! s event interval-ms)

adds an event to be yielded repeatedly at a fixed interval. Returns a TaskID for cancellation.
